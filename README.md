# openhhkb

An open-source hardware remapper for the **HHKB Studio** and **HHKB Professional Hybrid Type-S**.

> [!WARNING]
> openhhkb is not affiliated with, nor is it endorsed by HHKB, PFU (a Fujitsu company), or Topre Corporation. It is an independent project which attempts to create an open-source hardware remapper.
>
> You may void your warranty by using openhhkb. **Use at your own risk.**

> [!CAUTION]
> **Dangerous rolling release** — always verify the code you are running before sending anything to your keyboard. It is not guaranteed that the official HHKB keymap tool can recover the damage done!

## Status

This project is based on reverse engineering of the keyboards' configuration protocol. It is experimental, very risky, and **not recommended for normal users**. Nothing here is stable yet.
